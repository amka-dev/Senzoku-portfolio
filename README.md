## About

**Senzoku Portfolio** is a personal frontend portfolio project built with a premium minimalistic aesthetic and cyberpunk-inspired visual direction.

The project focuses on clean composition, smooth interactions, cinematic atmosphere, and expensive-looking UI design rather than overloaded functionality.

The portfolio includes:
- interactive 3D object
- smooth scrolling experience
- responsive layout
- animated sections
- project showcase
- personal skills section
- contact section
